# Архитектура «Шлейфа»

Срез исходного кода `43faf8a` ветки `live-2.0`, 11.11.2026.

Открой [атлас draw.io](shleif-architecture.drawio) либо [галерею](index.html). Каждая страница также доступна отдельно в `diagrams/` и как SVG в `svg/`.

Синий — механизм присутствует в коде; жёлтый — частичная интеграция; фиолетовый пунктир — целевой механизм; серый — внешний участник или пояснение. Наличие кода не означает подтверждение на живом стенде. «Основа» — предложенное, ещё не утверждённое имя.

## Как читать

Обзор: 01–02 → компоненты: 03–05 → данные и доверие: 06–08 → операции: 09–15 → данные, сеть и отказы: 16–18 → цель и разрывы: 19–20 → завершение и угрозы: 21–22.

Источники каждой страницы указаны в её подвале и в `manifest.json`. Схема БД логическая, а не точный SQL DDL. Состояния устройства — модель сценариев, а не единое поле БД. Старый `docs/SOLUTION.drawio` сохранён как историческое описание целевого решения.

## Воспроизведение

`python3 tools/diagram/architecture_atlas.py` создаёт XML и проверяет ссылки, уникальность ID и границы страницы. Экспорт всех SVG: `python3 tools/diagram/export_architecture.py`. Для PNG добавь `--png-dir /tmp/shleif-preview`. Для отдельного листа: `--only 08`. Нужен установленный draw.io Desktop. Для проверки расположения дополнительно открой отрисованные страницы. Это проверка документации, не работоспособности всей системы.
