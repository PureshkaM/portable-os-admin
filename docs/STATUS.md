# Статус: целевое решение → код

Таблица «требование [SOLUTION.md](SOLUTION.md) → где в коде → статус». Пополняется вместе с
каждой реализованной задачей: строка меняется в том же коммите, что и код с тестом.

Статусы:
- **готово, вживую** — прогнано на Linux или на стенде, дата прогона указана;
- **готово, не проверено вживую** — есть код и тесты, живого прогона не было;
- **частично**;
- **нет** — в коде отсутствует;
- **ждёт** — нужен ресурс (оборудование, решение Максима).
