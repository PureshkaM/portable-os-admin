# Ресурс отзыва: что должно быть на сервере

Носитель при каждой загрузке спрашивает у общедоступного ресурса, не отозван ли
он. Получив подписанный ответ «отозван», он уничтожает заголовок LUKS —
необратимо, за секунды. Этот документ описывает ровно то, что нужно поднять на
стороне организации, и почему именно так.

Ресурс **общедоступный** намеренно. Проверка обязана срабатывать раньше, чем
носитель дотянется до внутренней сети: ресурс во внутреннем контуре означал бы,
что отозванный носитель сперва попадает внутрь периметра, а уже потом узнаёт,
что он отозван.

## Запрос

```
GET <url>/state?media=<идентификатор>&nonce=<32 шестнадцатеричных знака>
```

`<url>` — то, что администратор задал в конфигурации (`revocation.url`), только
`https://`. Идентификатор носителя — тот же, что показан в списке носителей
(`media_id`, восемь знаков). `nonce` носитель генерирует сам при каждой
проверке из `/dev/urandom`.

## Ответ

Две строки, `text/plain`:

```
poa-state <media_id> <nonce> <состояние>
<подпись первой строки в base64>
```

Состояние — `ok` или `revoked`. Любое другое слово носитель считает за «ok»:
неизвестное состояние не повод уничтожать данные.

Первая строка подписывается **целиком, как есть, без завершающего перевода
строки**. Подпись — Ed25519, сырая (64 байта), в base64.

Пример:

```
poa-state 4cb868dc 9f2c...e1 revoked
q1Qw...==
```

## Почему так, а не иначе

**Почему `nonce`, а не время.** Это защита от повтора старого ответа —
единственное, что оставалось открытым в дизайне. Носитель не может доверять
своим часам: он переносной, батарейка садится, время сбрасывается. Подписав
случайное число, которое носитель прислал сию секунду, сервер делает вчерашний
ответ бесполезным без всяких часов и счётчиков.

**Почему подпись, а не HTTPS сам по себе.** HTTPS защищает канал и проверяется
цепочкой удостоверяющих центров, которая лежит в самой системе носителя, — то
есть тем, что злоумышленник с носителем в руках может подменить. Подпись
проверяется ключом, который положил администратор, и подменить его, не открыв
LUKS, нельзя. HTTPS при этом тоже обязателен, но по другой причине: по
открытому каналу видно, какие носители у организации есть и когда они
включаются.

**Почему сервер отвечает всем, а не только отозванным.** Сервер видит, какие
носители живы и когда отмечались, — это и есть учёт парка, ради которого
механизм отчасти и заводился.

**Чего сервер не должен делать.** Хранить что-либо, кроме списка
идентификаторов и их состояния. Никаких данных пользователя на носителе нет —
они на рабочем компьютере внутри компании.

## Ключ подписи

**Ключ отзыва — отдельный, а не тот, которым подписывается обмен
конфигурациями.** Сервер обязан подписывать ответы, то есть закрытая часть
ключа лежит на нём; сервер общедоступный, и рано или поздно его взломают. Ключ
обмена при этом остаётся в контейнере администратора и не покидает его никогда
— смешивать эти две роли значило бы отдать наружу то, чем удостоверяются
конфигурации между администраторами.

Пара ключей отзыва заводится в контейнере администратора. На носитель при
записи едет открытая часть (`/etc/poa/revocation.pub`, PEM); на сервер
администратор выгружает закрытую. Скомпрометированный сервер позволяет
злоумышленнику отозвать носители — то есть устроить отказ в обслуживании, —
но не открыть ни один из них.

## Проверка подписи на стороне носителя

Носитель проверяет так (это же можно выполнить руками при отладке сервера):

```sh
printf '%s' "$MESSAGE" > message
printf '%s' "$SIGNATURE" | base64 -d > signature
openssl pkeyutl -verify -pubin -inkey /etc/poa/revocation.pub \
    -rawin -in message -sigfile signature
```

`-rawin` обязателен: Ed25519 подписывает сообщение целиком, а не его хеш.

## Что происходит, когда сервер молчит

Ничего. Нет сети, ресурс недоступен, ответ непонятен, подпись не сходится,
ответ подписан не на этот запрос — во всех этих случаях носитель пишет строку в
свой журнал и работает дальше. Срока доверия («не отметился N дней —
блокируйся») нет: это решение пользователя, и причина в том, что носитель,
никогда не выходящий в интернет, до рабочего места всё равно не доходит.
