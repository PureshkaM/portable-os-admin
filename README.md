# Якорь

Система защищённого удалённого доступа к рабочим местам организации.
Сотрудник загружает Linux с переносного USB-носителя, проходит аутентификацию
и подключается к разрешённому рабочему месту через VPN.

## Состав решения

| Компонент | Назначение |
|---|---|
| Приложение администратора | Конфигурации ОС, сборка образов, выпуск и обслуживание носителей |
| Сервер доступа и управления | Активация, TOTP, выдача допуска, профили подключения, выпуски и события |
| Переносное устройство | Загрузочная среда с ограниченным рабочим столом MATE и клиентами доступа |
| Корень доверия организации | Заверение полномочий администраторов и выпусков |
| VPN-шлюз | Подключение носителя к разрешённым рабочим местам в сети организации |

Приложение хранит конфигурации, ключи и записи носителей в локальном
зашифрованном контейнере. Сервер доступа и VPN-шлюз развёртываются отдельно;
рабочие места и внутренняя сеть настраиваются организацией.

## Возможности

- Сборка общего образа Debian или РЕД ОС и выпуск персональных носителей из него.
- Зашифрованные тома состояния и журналов, привязка к разрешённым компьютерам,
  одноразовые коды восстановления.
- Активация носителя, вход с TOTP, сеансовый доступ через OpenVPN,
  подключения к рабочим местам по RDP и VNC.
- Образы ОС A/B (две области для обновления и возврата после сбоя), проверка
  целостности dm-verity и временный слой изменений в оперативной памяти.
- Группы носителей, назначение дистрибутивов, публикация подписанных выпусков,
  обновление и отзыв устройств.
- Просмотр журналов, передача событий серверу и зашифрованный обмен
  конфигурациями между администраторами.

## Требования

- Для приложения администратора — Linux с графическим сеансом и polkit.
  Пакеты предусмотрены для Debian и РЕД ОС; работа с дисками требует прав root.
- Для носителя — совместимый компьютер с UEFI и загрузкой с USB.
  В коде предусмотрены x86_64 и arm64; конкретное оборудование требует проверки.
- Для сборки — полный установочный ISO с пакетным репозиторием либо настроенный
  сетевой репозиторий. Обычный Live ISO и netinst не заменяют установочный DVD.
  По умолчанию сборка может получать пакеты и обновления из сети.
  Для профиля РЕД ОС `8.0c` нужен доверенный сертифицированный ISO.
  Сетевые обновления этого профиля берутся из HTTPS-каналов `8.0c` РЕД СОФТ
  с проверкой подписей RPM. Для сборки только с ISO отключи сетевые пакеты.
- Для записи — USB-накопитель достаточной ёмкости. Запись удаляет его содержимое.
- Для удалённой работы — доступный сервер управления, настроенный OpenVPN-шлюз
  и подготовленные рабочие места.

Для сборки другой архитектуры нужны QEMU и настроенный binfmt_misc
(механизм Linux для запуска программ другой архитектуры).

## Установка и первый запуск

Приложение устанавливается системным пакетом `.deb` или `.rpm`.
Пакеты доступны в [выпусках](https://github.com/PureshkaM/portable-os-admin/releases)
и [сборках GitHub Actions](https://github.com/PureshkaM/portable-os-admin/actions).
Версия пакета должна соответствовать используемым исходникам.
Пакет для Debian использует системные Python, Tkinter и cryptography.
Для РЕД ОС 8 интерфейс RPM использует GTK 3 и PyGObject. Их пакеты
(`gtk3` и `python3-gobject`) и остальные зависимости установки RPM доступны
на установочном ISO сертифицированной редакции.
Если зависимость отсутствует в разрешённых каналах, её конкретную версию
и источник до включения в поставку проверяет организация.

Для установки RPM с доверенного ISO смонтируй его в `/mnt/redos`
и запусти из каталога, где лежит пакет:

```sh
sudo dnf --repofrompath=poa-iso,file:///mnt/redos --repo=poa-iso \
  --setopt=poa-iso.gpgcheck=1 \
  --setopt=poa-iso.gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-RED-SOFT \
  install ./portable-os-admin-1.2.0-3.noarch.rpm
```

После установки команда запуска:

```sh
portable-os-admin
```

Приложение запросит права через системное окно polkit, затем предложит
создать или открыть контейнер администратора.

1. Разверни [сервер доступа](docs/REVOCATION-SERVER.md) и отдельный VPN-шлюз.
2. Создай контейнер администратора. В разделе «Обслуживание» подключись
   к серверу по его адресу и одноразовому коду знакомства.
3. Настрой корень доверия организации и подпись выпусков.
4. В разделе «Конфигурации» подготовь и проверь параметры ОС.
5. В мастере выпуска выбери ISO или готовый дистрибутив, целевой накопитель
   и данные сотрудника. Проверь выбранный диск перед подтверждением записи.
6. Назначь носителю параметры доступа и рабочие места, затем выполни
   активацию и проверь подключение на целевом компьютере.

## Разработка и проверки

Для запуска из исходников нужны Python 3.9+, polkit и системные пакеты
соответствующего интерфейса. На РЕД ОС GTK-версия запускается командой
`PYTHONPATH=src /usr/bin/python3 -m portable_os_admin.gui.gtk3`.
Для сборки и записи также
нужны системные утилиты и пакеты, включая cryptsetup, parted, squashfs-tools,
veritysetup, attr и debootstrap либо dnf для соответствующей целевой ОС.
Утилиты veritysetup нет на проверенном ISO РЕД ОС 8. Она требуется для
сборки образа с dm-verity.
Одна установка Python-зависимостей их не заменяет.

```sh
git clone https://github.com/PureshkaM/portable-os-admin.git
cd portable-os-admin
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/portable-os-admin
```

Проверки из каталога проекта:

```sh
.venv/bin/python -m pytest -q --basetemp=/tmp/yakor-tests
.venv/bin/python -m pyflakes src packaging/revocation-server
```

Графическим тестам нужен работающий дисплей, серверным — локальные сокеты.
Полный прогон сборки, записи, загрузки и восстановления выполняется на Linux
с тестовым носителем. На macOS часть проверок недоступна из-за зависимости
от механизмов Linux. Автоматические тесты не заменяют загрузку на оборудовании.

## Ограничения

- Аппаратный профиль токена-носителя и основной корень на Рутокене
  ещё не интегрированы в рабочий сценарий.
- Полный клиентский путь ViPNet, запечатанное хранилище серверных секретов
  и автоматическое переключение клиента на резервный адрес требуют доработки.
- Подпись образа и dm-verity не гарантируют доверенное исполнение ядра
  и initramfs до ввода фразы на чужом компьютере.
- Прошивка компьютера, аппаратный перехват ввода и фотографирование экрана
  находятся за пределами защиты загрузочной среды.
